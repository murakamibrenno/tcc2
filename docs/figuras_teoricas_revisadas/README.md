# Esquemas teóricos revisados

Diagramas vetoriais elaborados para a revisão documental. SVM: separação por margem, conforme Manning, Raghavan e Schütze (2008). Boosting: contribuições sequenciais de árvores, conforme Chen e Guestrin (2016). Esquemas conceituais, sem dados ou modelos ajustados do experimento. Os arquivos SVG são a fonte editável; PNGs são derivados para inserção no Word. As imagens históricas estão preservadas nas cópias anteriores do trabalho.
